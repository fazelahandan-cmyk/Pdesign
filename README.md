# پرشین دارک هورس

فروشگاه فارسی RTL با ۳۰ طرح HTML/CSS، پیش‌نمایش واقعی و ثبت سفارش از طریق تلگرام @PDH_SUP.

## راه‌اندازی روی سرور

نیازمند Node.js نسخه ۲۴ یا بالاتر است. وابستگی npm ندارد.

```sh
npm start
```

آدرس محلی: http://localhost:3000

در اولین اجرا، پایگاه داده SQLite در پوشه data ساخته و داده‌های نمونه درج می‌شوند. این پوشه باید قابل نوشتن باشد و نباید مستقیماً توسط وب‌سرور منتشر شود. فقط پوشه public عمومی است.

برای انتشار عمومی، دامنه و HTTPS را روی reverse proxy تنظیم کنید و پورت داخلی برنامه را مستقیم در اینترنت باز نگذارید. فایل نمونه متغیرها در .env.example آمده است؛ Node با دستور بالا فایل .env را خودکار بارگذاری نمی‌کند. برای استفاده از آن:

```sh
node --env-file=.env server.mjs
```

## امکانات این نسخه

- ۳۰ طرح در سه صفحه ۱۰تایی همراه پیشنهادهای هر صفحه
- فایل واقعی HTML/CSS و تصویرسازی SVG برای هر طرح در public/designs
- پیش‌نمایش جدا با sandbox و بدون اجرای اسکریپت
- دکمه خرید مستقیم و خرید سبد: نمایش پیام نبود درگاه و لینک https://t.me/PDH_SUP، بدون نیاز به ورود و بدون ثبت سفارش آنلاین
- جست‌وجو، دسته‌بندی، فیلتر قیمت، سبد، ثبت‌نام خریدار و فروشنده
- ثبت مشخصات قالب فروشنده برای بررسی مدیر
- مسیر مدیریت /AdminFezi با تأیید، رد و غیرفعال‌سازی قالب و تاریخچه اقدامات

## تنظیمات محیطی

- PORT: پیش‌فرض 3000
- DB_PATH: پیش‌فرض data/store.db
- APP_URL: مبدأ دقیق سایت مانند https://example.com
- NODE_ENV=production: کوکی Secure، نیازمند HTTPS
- ADMIN_EMAIL: ایمیل مدیر
- ADMIN_PASSWORD_HASH: هش scrypt با قالب saltHex:hashHex؛ salt تصادفی ۱۶ بایتی و خروجی ۶۴ بایتی. رمز مدیر یا حساب ثابت در بسته وجود ندارد.

## محدودیت‌ها

این نسخه پرداخت یا تسویه آنلاین ندارد؛ ثبت سفارش دستی در تلگرام است. فایل‌های طرح رابط استاتیک‌اند: فروش، رزرو، ابزار هوش مصنوعی یا خدمات تخصصی داخل پیش‌نمایش‌ها به بک‌اند جدا نیاز دارند. کپی و تصویرسازی پیش‌نمایش‌ها نمونه‌اند؛ شرایط تحویل، قیمت نهایی خدمات و مجوز را پیش از سفارش اعلام کنید.

بازیابی رمز با ایمیل، آپلود امن، لینک دانلود حفاظت‌شده، مدیریت کامل کاربران/دسته‌ها/تخلف/تسویه و ویرایش حساب تکمیل نشده‌اند. در پایگاه داده ۷۲ رکورد اولیه باقی می‌ماند؛ فقط ۳۰ طرح انتخابی در کاتالوگ عمومی ارائه می‌شود. طرح‌های فروشنده بعد از تأیید هنوز باید به کاتالوگ پیش‌نمایش‌ها اضافه شوند. اعتبارسنجی تولیدی و مدیریت مالی کامل نشده است.

این بسته بدون پایگاه داده، حساب‌های کاربران و اسرار ساخته شده است. آزمون‌های موجود با npm test اجرا می‌شوند. بررسی نحوی و آزمون‌های پایه انجام شده‌اند؛ اجرای سرور و آزمون بصری مرورگر در محیط ساخت به علت محدودیت پورت تکمیل نشد. قبل از انتشار عمومی در سرور مقصد بررسی شود.
